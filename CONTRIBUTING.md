# Contributing

Pull requests are welcome.

## Do not commit

- `data/ideas.sqlite` (anyone’s archive)
- `data/x_oauth.json` (API keys)
- `.env` (tokens)

Do not use X’s official logo.

Public download zip is built by `scripts/pack_pc_install.py` and must stay the **app only** (no `SKILL.md`, tests, or `dev/`).

The audiobalance.com/thatpost page source lives in `dev/landing/`.
